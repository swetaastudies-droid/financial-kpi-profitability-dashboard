# Financial KPI Monitoring & Profitability Dashboard

## Overview
A Power BI portfolio project designed to explore financial performance using revenue, costs, profitability, and budget KPIs.

## Business questions
- Which regions generate the highest revenue and profit?
- Which product categories are most profitable?
- Is actual revenue meeting budget?
- How does net profit margin change over time?
- Which sales channels perform best?

## Tools
- Power BI Desktop
- Excel / Power Query
- DAX

## Dataset
The included sample data is fictional and intended for educational use. Currency: INR.

## Dashboard pages
1. Executive Overview
2. Profitability Analysis
3. Cost & Expense Analysis
4. Budget vs Actual

## Key measures
- Total Revenue
- Total Cost
- Gross Profit
- Net Profit
- Net Profit Margin %
- Budget Variance
- Budget Achievement %
- Revenue MoM Growth %
